# Commit Rules

Apply these rules when creating a commit in this repository.

## Language and format

- Check `git log` and use the language of the existing commit history.
- Prefer a concise, single-line summary. For complex changes, add short body
  paragraphs after a blank line.

## Content

- Describe what the code does now. Omit workflow labels such as "Review response"
  or "レビュー対応".
- Omit review finding IDs such as `C-1`, `M-1`, `mi-1`, and `I-1`.
- Add `Co-Authored-By:`, `Signed-off-by:`, or AI-attribution trailers only when
  explicitly requested by the user.
